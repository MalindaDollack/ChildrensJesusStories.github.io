# Malinda's Story Garden Website

A complete static website prepared for GitHub Pages.

## Upload to GitHub

1. Create a free GitHub account.
2. Create a new **public** repository named `malindas-story-garden`.
3. Open the repository and choose **Add file → Upload files**.
4. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the entire `assets` folder.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Choose branch **main**, folder **/(root)**, and press **Save**.
8. GitHub will show the website address after it finishes publishing.

## Important notes

- The website is ready to display on GitHub Pages.
- Book ordering buttons currently say **Coming Soon**.
- The contact form opens the visitor's email program.
- Reviews and character votes are stored only in the visitor's browser. A database service will be needed later for public reviews shared by everyone.
- Photo and artwork buttons preview a selected file, then ask the visitor to email it to Malinda. A secure upload service will be needed later for direct website uploads.
